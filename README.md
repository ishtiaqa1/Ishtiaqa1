## 🚀 Featured Projects

### [Kin](https://github.com/Care4Kin/kin)
Full-stack elder-care dashboard built as my Marcy Lab capstone — presented at Cognizant. Combines financial monitoring with LLM-powered scam detection to help families protect elderly relatives.
`React 18` `Vite` `FastAPI` `PostgreSQL` `Plaid API` `Groq / LLaMA`

### [Marcy the Simulation](https://github.com/Ish-Darlin-Sina/marcy-the-simulation)
Winner of the Marcy x Envelope Hackathon. A simulation game built collaboratively under a tight hackathon timeline.
`JavaScript` `Game Simulation`

### [FRED Dashboard](https://github.com/ishtiaqa1/Fred-DashBoard)
Financial data dashboard pulling live economic indicators from the Federal Reserve's FRED API, with server-side caching for performance.
`React` `Express` `Chart.js` `FRED API`

### [Mahjong](https://github.com/ishtiaqa1/Mahjong)
Multiplayer Mahjong game with a full lobby system for real-time play.
`React` `PHP` `SQL`
